# 主导航菜单重构：发布/配置双分组

> 创建日期：2026-08-23
> 状态：待实施
> 关联分支：feature/配置向导（路由重构与向导功能无代码耦合，可并行）

## 一、需求概述

当前主菜单有 8 个可见一级入口，「SMOM」分组命名指代不清、归类标准不一致（项目管理/应用配置在分组内，性质相同的服务器/TFS/Git 却在分组外）。本次按功能性质重组为「发布」「配置」两个分组，一级可见入口从 8 个降为 5 个，使菜单分组逻辑自洽，并顺带清理 `/smom` 路径前缀等历史包袱。

## 二、功能边界

### 包含范围

- 重写 `src/router/route.ts` 的 `dynamicRoutes[0].children`：新建「发布」「配置」两个分组节点，删除 `/smom` 分组节点
- 3 个叶子路由路径变更（去掉 `/smom` 前缀）：`/smom/project → /project`、`/smom/appconfig → /appconfig`、`/smom/papersPublish → /papersPublish`，并同步改路由 name
- 3 个视图组件 name 同步改名（keepAlive 机制要求组件 name === 路由 name）
- i18n 三语文件 router 段新增 `publish`、`config` 两个 key，删除废弃的 `smom` key
- 可选清理：papersPublish 路由图标与页内一处「手动发布」日志文案

### 不包含范围

- 不删除、不合并任何页面功能（papersPublish「文件发布」页面保留，仅归类移动）
- 不迁移 `src/views` 目录结构、不改文件夹名（现有 path 与文件夹对应关系本就宽松，如 `/tfs` vs `teamFoundationServer`）
- 不动隐藏路由 `/sshInstall`
- 不调整 tagsView 多页签机制（"页签多"的体感问题可另行在主题配置中关闭 tagsView，不属于本次范围）
- 不做菜单排序/分组配置化

## 三、核心变更对象

### 1. 新路由结构（`src/router/route.ts`）

```
发布  /publish   (分组, icon: smom-icon smom-icon-fabu, redirect: /home)
├─ 发布平台  /home           (isAffix: true 保留, title: 项目发布)
└─ 文件发布  /papersPublish  (原 /smom/papersPublish, name: papersPublish)

配置  /config   (分组, icon: ele-Tools, redirect: /project)
├─ 项目管理  /project        (原 /smom/project,    name: project)
├─ 应用配置  /appconfig      (原 /smom/appconfig,  name: appconfig)
├─ 服务器    /server         (原一级入口迁入, name/路径不变)
├─ TFS      /tfs            (原一级入口迁入, name/路径不变)
└─ Git      /git            (原一级入口迁入, name/路径不变)

备份记录  /backups   (独立一级, 不变)
设置      /settings  (独立一级, 不变)
关于      /about     (独立一级, 不变)

```

- 一级可见入口：8 → 5
- 分组节点写法照抄现有 `/smom` 分组：`component: () => import("@/layout/routerView/parent.vue")` + `redirect` 到首叶子；子路由用绝对路径（以 `/` 开头），现有代码已验证该写法

## 六、注意事项

- **一次性缓存失效**：开启「缓存 tagsView」的用户，Session 中 `tagsViewList` / `keepAliveNames` 存有旧路径旧 name，升级后首启可能残留一个 404 页签，手动关闭即消失，无需兼容代码。
- **路径无外部依赖**：本项目为 Tauri 桌面应用，路径不出现在书签/外链场景；全库 grep 已确认除 `route.ts` 外无 `/smom/*` 路径与 `smomXxx` name 引用（`deployTaskRecorder` 等文件里的 `'papersPublish'` 字符串是 DeployTaskSource 类型字面量，与路由无关，无需改动）。
- **vue-router 子路由绝对路径**：新分组子节点 path 以 `/` 开头（照抄现有 `/smom` 写法），避免路由嵌套拼接出 `/publish/smom/...` 之类的错误前缀。
- **分组图标**：「发布」组复用 `smom-icon-fabu`（与发布平台叶子同图标，子菜单展开时视觉重复可接受）；「配置」组用 Element Plus 内置 `ele-Tools`，不依赖 iconfont CDN 是否含合适图标。
- **回滚成本低**：本变更集中在 route.ts + 3 个 i18n 文件 + 3 处组件 name，git revert 即可整体回退。
